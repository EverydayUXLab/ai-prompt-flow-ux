# AI Prompt Flow & Response UX Review

This project presents an anonymized UX and performance-perception audit of an AI-driven product where users experienced confusion and low trust despite strong model performance.

## Focus
- Prompt clarity and sequencing
- Response framing and confidence signals
- Retry, fallback, and failure states
- System feedback during latency

## Key Insight
Most usability issues stemmed from UX and system feedback gaps — not model quality.
